## 🎯 Účel projektu

Ševčík CMD je **experimentální interaktivní příkazové prostředí** napsané v Pythonu.  
Cílem projektu je:
- vytvořit vlastní „mini shell“
- testovat práci se systémem, soubory a sítí
- experimentovat s tab-completion, oprávněními a GUI fallbacky
- učit se a bavit se 😄
